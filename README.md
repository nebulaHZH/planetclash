# PLANET CLASH · 星球之心争夺战

第一人称双星球攻城战。两颗布局完全一样、只有颜色不同的星球（糖果星球 / 紫色星球），双方各有队友。搭乘定时往返的飞船，或亲自驾驶有燃料的火箭突袭敌方星球，拆掉守护大塔，夺取星球之心。阵亡会在己方星球重生，战斗不中断。

**外部资源只有模型**：没有 CDN、字体文件、图片或音频文件。贴图由 Canvas 实时绘制，音效由 Web Audio 合成，地形与掩体全部由代码生成。

## 操作

| 输入 | 动作 |
| --- | --- |
| `WASD` | 移动（沿球面，重力指向球心） |
| `F` | 靠近飞船/火箭坪时登船；骑乘时下车 |
| `E` | 飞船自动驾驶 / 手动接管切换 |
| `G` | 飞行中弹射火箭 |
| 鼠标 | 视角；骑乘时转向 |
| 左键 | 射击 / 骑乘时开炮 |
| `W` | 骑火箭时推进（消耗燃料） |
| `Space` | 跳跃 |
| `Shift` | 冲刺 |
| `R` | 换弹 |
| `1`…`6` | 切换武器/工具 |
| `Esc` | 暂停 |

## 玩法

- **目标**：拆掉敌方星球之心旁的最大防御塔，站上心 7 秒夺取它即获胜；己方主塔被毁且敌方士兵占住我方心则失败。
- **双星对称**：两颗星球用同一套本地布局，只是配色不同——各有 1 大塔护心 + 4 中塔环绕 + 6 小塔稀疏散布、建筑、可挖的地面。
- **飞船舰队**：5 艘飞船错峰循环往返，天空中始终有船在飞、有船即将抵达。靠近发光停机坪按 `F` 登船，可选自动驾驶（`E` 切换手动接管），飞行中左键开炮打防御塔，塔也会反击飞船。HUD 顶部显示「飞船在途 N」。
- **火箭**：星球上的火箭坪按 `F` 直接驾驶，或飞行中按 `G` 从飞船弹射。必须手动操控方向，`W` 推进消耗燃料；燃料耗尽或卡在半空会被引力拽向更近的星球，硬着陆会坠毁重生。
- **血条**：所有防御塔、士兵和英雄头顶都有实时血条（我方绿、敌方红），随受伤缩短、阵亡隐藏；英雄另外带名字牌。HUD 顶部另显示双方英雄血量。
- **英雄**：每方各有 1 名戴王冠、带名字牌的英雄（我方「糖果骑士」、敌方「紫晶英雄」）。比普通士兵更硬、更快、打得更疼，带头冲锋。击杀敌方英雄计入 KDA 击杀，阵亡后 9 秒复活。
- **弹药补给**：两颗星球的停机坪旁各有一个发光黄色补给箱，靠近即自动补满备弹，8 秒冷却（冷却时变暗）。HUD 会提示附近补给是否就绪。
- **队友与复活**：双方各有 2 名 AI 士兵外加 1 名英雄，会登船、登陆、拆塔、夺心。AI 对建筑只造成约半伤、首波延后且阵亡后重新集结，给玩家充足攻防时间；阵亡后在己方星球满血重生，只有星球之心被夺才结束战斗。
- **挖掘**：小铲子对同一处反复挖会不断加深，敌方星球可挖到 6 米地层、形成能站进去的深坑；糖果星球还保留原有的漏斗式深挖与梯子。
- 命中头部 1.9 倍伤害；击倒爆彩纸、弹珠和「KO!」贴纸，没有血腥表现。

## 技术要点

- **球面重力**：位置始终归一化到 `surfaceRadius(dir)` 的解析地表，`up` 恒为当地径向；相机由 `up + heading + pitch` 重建，任意纬度都保持正立。
- **第一人称武器**：独立 `viewScene` + `viewCamera` 渲染枪模，避免被场景裁剪；HIP / ADS 两套姿态插值，带呼吸、摆动、后坐与换弹下沉。
- **卡通渲染**：`MeshToonMaterial` + 3×1 三阶渐变贴图，反向外壳描边，blob 圆形阴影（不用实时阴影贴图）。
- **程序化世界**：顶点着色的多生态星球（薄荷 / 果冻 / 砂糖 / 冰），InstancedMesh 散布 8000+ 草花石，出生点额外加密。
- **曲率遮挡**：`hasLineOfSight()` 用解析地平线判断敌我视线，枪口为起点。
- **性能**：对象池（子弹 / 粒子 / 彩纸）、共享材质、`InstancedMesh`，目标 60fps；实测 1440×813 下约 60fps。

## 目录

```
src/
  config.ts          色板、物理、玩法、角色与武器数值
  types.ts           HUD / 事件 / 结算类型
  App.tsx            菜单、HUD、暂停、结算、事件分发
  styles.css         全部 UI 与响应式布局（≥1080px 菜单分屏）
  game/
    Game.ts          渲染循环、相机、输入、射击、据点、生命周期
    player.ts        球面移动、跳跃、体力、头部摆动
    world.ts         星球、天空、地面细节、据点、地标
    enemies.ts       敌人 AI、血条、子弹池、曲率视线
    weapons.ts       三把 GLB 枪模的第一人称手套 / 手感
    toon.ts          卡通材质、描边、角色、程序化贴图
    fx.ts            粒子 / 彩纸 / 轨迹 / 光环
    audio.ts         Web Audio 合成音效
```
